https://github.com/thefriendlyhedgehog/MissingShip (private). Its own git repo nested in the AI_Projects repo.
**Engine (MS-007, 2026-09-25): private repos MissingShip-Shipwright / MissingShip-libultraship / MissingShip-ZAPDTR,
branch `missingship`** (full SoH history; base tag 9.2.3 = cb71e22; NOT GitHub forks -- forks of public repos are
always public). **Since MS-014 the engine is the `engine/` SUBMODULE of MissingShip** (MissingShip/engine; ../Shipwright is only a
compat symlink to it; build dir engine/build-ml, Ninja Release). After committing+pushing in engine/, commit the
`engine` pointer in MissingShip (check.py fails otherwise). Remotes in engine/: `origin` = private fork, `upstream` = HarbourMasters. Engine work = commits
on missingship (MS-nnn subject) + push, then `tools/genpatch.py` regenerates docs/*.patch (generated, not the source
of truth; `--check` for staleness). Submodule changes: commit+push in the submodule first, then the pointer.

The user deliberately committed the ROMs, .o2r archives and the app ("Add everything", 2026-09-25) so cloud sessions
can work, and removed .gitignore. **The repo must stay private forever** -- never make it public or copy those files
into a public repo. I declined to push ROMs myself; the user did it.

**Issue workflow (2026-09-25):** 50 GitHub issues filed from docs/ROADMAP.md, titled `MS-nnn: ...` (MS-001..MS-093,
GitHub #1-#50), 9 milestones (M0 Team footing, M1 Verify, M2 Data-only quick wins, M3 Actors by scene, M4 Link,
M5 Front end, M6 Drop-in, Platforms, Porting kit), labels port/infra/platform/needs-playtest/bug. Commit subjects
carry the MS id and `Fixes #N`; move closed rows to ROADMAP's Done section. New issues take the next free MS id.

Related: [[missingship-goal]], [[missing-link-soh-port]].

**Paths (MS-001, 2026-09-25):** all tools/pipeline scripts resolve inputs via `pipeline/mspaths.py`
(env `MS_*` overrides; `python3 pipeline/mspaths.py` prints them). Debug ROM = `roms/oot-mq-debug-pal.z64` (committed by the user; no env var
needed). `cycle.sh` is gone; the build is `python3 pipeline/ms_cycle.py [--no-launch]` (MS-082; `ms_cycle.sh` is a wrapper). Verify pipeline refactors by comparing a
per-entry md5 manifest of pipeline/ml.otr before/after, and `git restore` the rebuilt .o2r/.otr (identical content)
instead of committing them.

**Inventory (MS-005, 2026-09-25):** docs/ML_ACTOR_INVENTORY.md is GENERATED by `tools/survey_actors.py --write` ; only the Status/Verified cells are hand-edited and they carry over by slot. Don't hand-edit other
columns. Spawn scans must read an overlay's TEXT section only (data read as code gave false spawners). Ledger guard:
`tools/checkledger.py`.

**Gate (MS-008):** `python3 tools/check.py` (~3 s; `--build` adds the engine build) must pass before pushing; the
committed `.githooks/pre-push` runs it (enabled locally via `git config core.hooksPath .githooks`). Its hash check allows
exactly the 9 IA4 refs in pipeline/unresolved.json (MS-015). Injected-fault testing proved each check fails correctly.
