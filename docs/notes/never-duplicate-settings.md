Never duplicate settings. The MissingShip settings page holds only MissingShip's own options; stock SoH options (Text Speed, Skip Text, Remember Save Location, D-pad equips, D-pad ocarina, ...) stay only in SoH's own menus. Point to them by path in a tooltip if needed. Prefer SoH's built-in setting over a fork option that does the same (e.g. Persistent Masks replaced our Keep Bunny Hood).

**Why:** On 2026-09-26 the owner said "remove our text speed if we can just use SHIPs" and then "Never duplicate settings" when I had mirrored stock options on the MissingShip page.

**How to apply:** Before adding a widget, check whether SoH already has the setting; if so, don't add it. Related: [[owner-overrides-ml-look]].
